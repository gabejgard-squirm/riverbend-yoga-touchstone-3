# Riverbend Yoga Studio Touchstone 3

Sophia Introduction to Web Development coursework.

This repository contains the Touchstone 3 version of the Riverbend Yoga Studio website, including four HTML pages, the shared responsive CSS stylesheet, and yoga media assets.

[View the Touchstone 3 website](https://gabejgard-squirm.github.io/riverbend-yoga/)

The main branch and GitHub Pages site are the version submitted for Touchstone 3 grading.

## Related coursework

The JavaScript version is in the separate [Touchstone 4 repository](https://github.com/gabejgard-squirm/riverbend-yoga-touchstone-4). You can also [view the Touchstone 4 website](https://gabejgard-squirm.github.io/riverbend-yoga-touchstone-4/).

## Run in GitHub Codespaces

1. Open this repository and choose Code > Codespaces > Create codespace on main.
2. In the terminal, run:

   ```sh
   python3 -m http.server 8000
   ```

3. Open port 8000 from the Ports tab. To share the IDE preview, change that port to Public and copy its forwarded address.

The IDE preview requires a running Codespace. The GitHub Pages website above is available independently.
